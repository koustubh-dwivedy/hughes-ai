# HUG-256 — Wire custom domain app.tryhughes.com (per-issue plan)

## Goal

Make the deployed app reachable at `https://app.tryhughes.com/` instead of (or in addition to) the default `https://tryhughes.web.app/`.

## Why this issue stays docs-only

`tryhughes.com` is registered with Namecheap and its DNS is hosted at Namecheap (`dns1.registrar-servers.com`). Adding DNS records requires logging in to Namecheap's panel — there's no programmatic GCP path for it, and asking for Namecheap credentials creates an unnecessary security exposure. The records themselves are trivial; the operator can paste them in 2 min.

Adding `app.tryhughes.com` is fully additive to existing records:
- Apex `tryhughes.com` → marketing site on Google Sites (untouched).
- `www.tryhughes.com` → CNAME to `ghs.googlehosted.com` (Cloud Run domain map for `hughes-website`, untouched).
- MX → Zoho mail (untouched).
- **New:** `app.tryhughes.com` → Firebase Hosting (added here).

## Operator steps (these go into `infra/README.md`)

1. **Trigger Firebase Console to create the custom-domain spec.**

   In a browser: Firebase Console → project `tryhughes` → Hosting → "Add custom domain" → type `app.tryhughes.com` → click "Continue".

2. **Firebase returns one TXT record (for verification) + two A records (for traffic).** Copy the exact values shown.

3. **Add the records at Namecheap.**

   In Namecheap dashboard:
   - Domain List → `tryhughes.com` → Manage → Advanced DNS.
   - Add a new record:
     - Type: `TXT Record`
     - Host: `app` (or `_acme-challenge.app` depending on what Firebase shows)
     - Value: (the TXT value from Firebase)
     - TTL: Automatic
   - After Firebase verifies ownership (~5–15 min), it will tell you to remove the TXT and add the A records:
     - Type: `A Record`
     - Host: `app`
     - Value: (first IP from Firebase, e.g. `151.101.x.x` or `199.36.158.x`)
     - TTL: Automatic
   - Add a second A record with the same Host but the second IP value.

4. **Wait for SSL provisioning.** Firebase issues a Google-managed cert automatically ~20–30 min after DNS resolves.

5. **Verify.**

   ```bash
   dig +short A app.tryhughes.com           # returns Firebase IPs
   curl -sI https://app.tryhughes.com/      # 200, valid cert
   curl -sI https://app.tryhughes.com/api/health   # 200
   ```

6. **Mark this issue Done** on Linear once the URL is live.
